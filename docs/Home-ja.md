# ゼノギアスの逆コンパイル

非公式のゼノギアス保存活動、-Project Exodus- の一部です。

ゼノギアス（PlayStation、1998 年）のマッチング逆コンパイルです。このリポジトリの C をコンパイルすると、北米版（SLUS-00664）と日本版（SLPS-01160）のすべての実行ファイルとコードオーバーレイ、計 50 ファイルが 1 バイトもたがわず再現されます。逆コンパイルは完了しています。コンパイラが生成した関数はすべて C になっており、コードの約 98% を占めます。残りは主に `main` にあり、元のゲームでも手書きのアセンブリだった部分（ソニーの PSY-Q ライブラリと、ゲームの描画コードの一部）なので、アセンブリのまま残し、ビルド時にお手元のディスクから取り出します。

ゲームデータは含まれていません。ディスクはご自身でご用意ください。

## PC 移植版

同じ C から、ネイティブの PC 移植版 [EtherAura/xenogears-pc](https://github.com/EtherAura/xenogears-pc) もビルドできます。ソース中の `#ifdef PLATFORM_PC` ブロックはこの移植版のためのもので、PlayStation 向けのビルドでは何も生成しません。
